## Implementation scope

- The motion context now observes desktop width, fine pointer and reduced motion. Crossing 768 px removes desktop hero/title/depth transforms instead of leaving them on the mobile composition. Already read text does not replay on breakpoint changes.
- Native feature disclosures schedule one geometry refresh, keeping later scene entrances aligned after their height changes. Initial font/image completion and bfcache restoration use the same scheduler.
- The gallery decodes a requested frame before moving, ignores stale rapid requests, and keeps a failed destination from replacing the visible image. Pointer capture/cancellation distinguishes horizontal gestures from ordinary vertical scrolling. Hidden slides are inert.
- Dialog focus is restored to the actual trigger, including Safari button clicks and dialog-to-dialog transitions. Menu expanded state is explicit. Stable scrollbar space prevents scene resizing when a dialog opens.
- The plan computes its initial geometry after opening, reclamps after image load and viewport changes, and clears cancelled/lost pointer state. Short dialog entrances only run when reduced motion is off.
